# Мурчалкинс — Telegram Mini App

Готовое статическое веб-приложение: 10 цветных страниц комикса, перелистывание, 10 квизов × 5 вопросов (4 варианта ответа), объяснения правильных ответов, локальный прогресс чтения и лучшие результаты и 10 наград за квизы (от 4 правильных ответов из 5).

## Локальный запуск

Распакуйте ZIP. В папке проекта запустите `python3 -m http.server 8000` и откройте http://localhost:8000. Можно запустить и в обычном браузере; Telegram SDK при этом необязателен.

## Подключение в Telegram

1. Опубликуйте всё содержимое папки как статический сайт на HTTPS-хостинге (например GitHub Pages, Netlify, Vercel). Сохраните структуру файлов `index.html`, `style.css`, `app.js`, `data.js`, `assets/`.
2. Через @BotFather создайте бота командой `/newbot`, если его еще нет.
3. В @BotFather используйте `/newapp` для регистрации Mini App, укажите URL опубликованного сайта; либо `/setmenubutton`, чтобы открыть сайт через кнопку меню бота.
4. Откройте Mini App из Telegram и проверьте свайпы, ответы квиза и сохранение результатов.

## Примечания

Это frontend-прототип без сервера. Данные о прогрессе хранятся в localStorage конкретного устройства / Telegram WebView и не синхронизируются между устройствами. Нет регистрации, отправки результатов боту и единой базы пользователей. Для этих функций нужен backend и проверка подлинности Telegram initData на сервере. **Не добавляйте токен бота во frontend-файлы.**
